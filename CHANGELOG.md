# Changelog

## Unreleased

### Added

- **The language specification.** [`docs/RUTHENIAN.md`](docs/RUTHENIAN.md) is
  now in the repository and is **normative**: eight cases, three numbers, three
  declensions, six conjugation classes, three past tenses, with the etymology of
  each restored category. `docs/COMPARATIVE_GRAMMAR.md` carries the measured
  evidence behind it, `docs/sources/` holds the source-language studies the
  lexicon reconstructs from, and `docs/README.md` states which document outranks
  which.
- `INVARIANTS.md` — the falsifiable properties, each with the command that checks
  it, including the separation of measured source-language claims from the
  specified Ruthenian ones (I7) and the three quantities that are never averaged
  (I3).
- `tools/` — the source-language measurement scripts every published figure about
  Russian, Ukrainian, Belarusian, OCS and Polish is generated by.

### Changed

- **The project is a constructed language, not a Russian NLP tool.**
  `DIRECTION.md` had opened by denying the specification — "Ruthenian is Russian
  written in a Latin alphabet", "every lemma comes from attested Russian", "not a
  conlang" — while contradicting itself two sections later. That framing made the
  evaluator incoherent: the baseline was specified as reproducing standard
  Russian, but `domogo`, `doma` (abl), `domje` (voc), `druzi` and the whole dual
  column have no Russian counterpart to score against. The baseline is now the
  specification; attested cognates are evidence for reconstruction; comparison
  with Russian is reported as a distance and never as accuracy.
- **No configuration axis.** Generation is `(entry, slot) → Option<Form>`. An
  earlier design proposed a `Variant` switching `RUTHENIAN.md` §13's open
  questions; it was wrong mechanically (every such rule is permanently disabled
  while the question is open, so every affected rule grows a dead branch) and
  categorically (§13's entries are decisions awaiting an answer, not options a
  caller picks). An open question now blocks the paradigm it affects rather than
  parameterizing it. Provenance survives as the trace, which describes an answer
  rather than selecting one.
- **The conformance corpus is a committed artifact**, extracted from
  `RUTHENIAN.md` once and reviewed, not parsed live inside a test assertion.
  Fusing the two was tried and failed silently — a heading match compared one
  paradigm's forms against another's while reporting a clean run — so extraction
  and assertion are now separate steps with a currency check between them.
- Source-language classifications (Zaliznyak classes, accent letters, Russian
  stem classes) are extraction-time input and appear in no public type;
  `docs/RUSSIAN_GRAMMAR.md` moves to `docs/sources/`.

- **`ruthenian-orthography` 0.1.0** — bijective Cyrillic↔Latin conversion, the
  workspace's first crate. Zero dependencies.
  - The round-trip contract holds by construction: a greedy longest-match reader
    defines how Ruthenian is read, and the writer inserts the separator `'`
    exactly where re-reading its own output would diverge.
  - The alphabet is declared, and includes four context rules — the environments
    of `ъ`, `ь` and `й`, and hard-sign case agreement — which let the reverse
    direction decide rather than guess. Each was validated against 41 462 lines
    of Russian prose before being declared.
  - Case is a separate layer: ALL-CAPS tokens get ALL-CAPS digraphs
    (`ЩУКА` → `SZCZUKA`), everything else Title-case ones, and mixed case
    round-trips without a special path.
  - Stress is carried as a combining acute on the Latin vowel (`pisátj`).
    Stressed and unstressed spellings are different strings.
  - `to_latin` is strict; `to_latin_mixed` transliterates declared runs only and
    reports skipped spans, returning `String` rather than `Ruthenian` because its
    output does not participate in the contract.
  - 11 guards, each verified to fail under its stated mutation.

Measured against the reference implementation
(gold-silver-copper/ruthenian@49d3af7) on the same corpus: **0 round-trip
failures against its 3** (lines 12695, 13444, 31725).
